## Kako se dobijaju

Skenovi su vlasništvo izdavača, pa izvorne datoteke i izvedeni asseti **nisu u repozitoriju**. Svaka mašina ih pravi sama:

```sh
pip install gdown
npm run scans:fetch      # preuzima i provjerava SHA-256, oko 1 GB u .local-data/scans
npm run scans:prepare    # pravi public/assets/scans (oko 95 MB) i src/data/scan-assets.local.json
```

`scans:prepare` obrezuje crni rub skenova, okreće žetone uspravno i smanjuje slike (karte na 720 px, listovi likova na 1.900 px) u WebP. Izlaz ide u `public/assets/scans/` i u `src/data/scan-assets.local.json`; oba su u `.gitignore`.

Bez tih datoteka igra radi kao ranije s ilustrovanim licima. `src/campaign/scan-assets.ts` učita manifest ako postoji, a sve komponente biraju sken samo za ono što je pripremljeno, pa i djelimičan set radi. Testovi uvijek koriste ilustrovana lica.

Build bez skenova provjeren je u Chromiumu: biblioteka prikazuje ilustrovana lica, trag iskustva portrete, nema dugmeta **Printed sheet** i nema nijednog zahtjeva za sken.

## Javno objavljivanje

Produkcijska igra na Vercelu i GitHub repozitorij su javni, a skenovi su umjetnička djela i tekst Fantasy Flight Games i Blizzarda. Zato produkcijski build namjerno koristi ilustrovana lica. Kad bi se `public/assets/scans/` i manifest dodali u Git, svako ko otvori igru preuzimao bi cijele skenove, a repozitorij bi ih distribuirao. To je odluka vlasnika projekta; za lokalnu igru nije potrebna.
