# Illustrated board refresh

Generated with the built-in imagegen tool on 27 September 2026. Terrain, quest deck backs and map counters are generated artwork. Region geometry, movement borders, labels, routes, quest references and counts remain live SVG/HTML in English. The existing imagegen portraits, card illustrations, frame, parchment and war hall remain part of the same art system.

The terrain uses the exact 3:2 board viewport (`135 95 1380 920`), rendered from the traced geometry as a layout reference. It does not define passability. Original PNGs are preserved in `.local-data/imagegen-sources/`; optimized WebP copies ship from `public/assets/warcraft/`.
