# Character sheets and individual artwork · v3

Generated with the built-in Imagegen tool on 27 September 2026. No external API key was used.

## Delivered assets

- `public/assets/warcraft/sheet-folio-v3.webp`: the ornamental leather/brass sheet material.
- `public/assets/talent-art/`: 108 individual talent illustrations, one for each talent.
- `public/assets/event-art/`: 19 event themes, four auction items, and one closed spellbook.
- `public/assets/card-art/`: 402 illustration windows extracted from the locally supplied scans (generated talents supersede the original talent emblems).
- `public/assets/portraits/`: 16 character and three Overlord portraits isolated from the existing generated atlases.

The scans supply illustration windows only. Text, costs, capacities, card rules and equipment slots are live interface elements. Full portrait cells are extracted before display, avoiding neighbouring faces. Item and spell artwork uses `object-fit: contain`; the code never stretches a square illustration across a rectangular banner.

Rebuild source extractions with `npx tsx scripts/prepare-card-art.ts`. Generated source atlases are preserved locally in `.local-data/imagegen-sources/talents-v3-{0,1,2}.png` and `events-v3.png`; use `npx tsx scripts/prepare-generated-art.ts` to rebuild their individual assets. The generated manifest overrides the source manifest for talent and auction cards.
